# 最初限定

一个独立可玩的《先验观念论体系》交互序章。发布内容位于 dist/，无需安装依赖。

打开 dist/index.html 即可离线游玩，也可以把 dist/ 交给任意静态网页服务器。

## 流程

无界活动留下消散的痕迹；点击留点；拖动画线；回到起点或选择闭合；进入轮廓；画出自己的形象；生成两个联动视角。支持鼠标、触摸和键盘。重画、重新开始及回看说明均在页面内。

双视角左侧为根据玩家位置与轮廓计算的第一人称边界投影，右侧显示同一个玩家位置及手绘形象。中间界限可在 25%—75% 之间拖动。

## 哲学边界

游戏依照用户提出的画图、框定自身与双视角设想，并参考所提供的第三章、第一时期 A 及附论笔记。操作顺序为学习隐喻，并非声称复现谢林原文中的心理发生步骤。有限形象不等于自我整体，空间墙面也不等于原始限定；第三人称不是绝对观察者。暂不展开后续“无限长头”机制。

## 验证

JavaScript 语法检查通过。使用模拟事件与画布接口检查了完整流程、区域外落笔、移动边界、分屏拖动范围、小区域拒绝和重新开始。未进行真实浏览器或实机触摸验证。

## 交互更新

未闭合的落点与线段保留 3 秒后渐隐，12 秒后从画面及闭合判定中移除。绘画使用无界世界坐标；按住笔尖靠近屏幕任一边缘，镜头持续向该方向移动，画面内容向反方向移动。笔尖在屏幕上的位置保持不变，新的线段继续生成。松手、切换到后台或离开窗口时停止平移。闭合后自动将轮廓收进视野，并保留它供后续游戏使用。

新增逻辑验证：淡出时间、过期几何移除、四边连续平移、笔尖屏幕位置不漂移、场景反向移动、松手停止以及重新开始重置镜头。

The boundary prompt is delayed until the player holds a drawing at a viewport edge, the view pans, and the world-space camera offset passes the discovery threshold. The initial exploration trace is then cleared and a fresh mark starts the player-created boundary.
